# azm thank-you cards

Personalized "thank you" cards for نادي عزم board/committee members, revealed via a unique code (`?code=N`) with a themed planet reveal per person.

- `index.html` — the card page (reads `?code=` and optionally `?name=` from the URL)
- `باركودات-مجلس-الادارة-العليا.html` — printable QR barcode sheet for the newest 5 board members (codes 16–20). Open it and set `BASE_URL` at the top of its script to this site's published URL before printing/distributing.
